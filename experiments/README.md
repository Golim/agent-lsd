# RAW Data

The full artifact (including scripts to run the experiments, prompts, logs and LLM transcripts) is approximately 390 MB of compressed archive, and is not stored in this Git repository. It is available at:

[[Raw Data Archive]](https://doi.org/10.6084/m9.figshare.33095564)

To extract the data, download the archive and run:

```bash
tar -xzf raw_data.tar.gz
```

SHA256 checksums are provided in `experiments.tar.gz.sha256` and `experiments.contents.sha256`.
